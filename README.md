## Featured Projects

### 📊 Woolworths Financial Performance Analysis

An end-to-end data analysis project examining Woolworths Group's financial performance between 2021 and 2025.

I collected financial data from Woolworths Group's annual reports and financial results, selected and organised the relevant datasets, and cleaned the data using Python and Pandas. The cleaned data was loaded into PostgreSQL for SQL analysis before being visualised through four interactive Power BI dashboard pages.

The project analyses revenue growth, profitability, operating costs and the performance of Woolworths' major trading segments. Further analysis was conducted on W Living after it was identified as the segment with the clearest deterioration in financial performance.

**Tools:** Python, Pandas, PostgreSQL, SQL, Power BI, DAX
